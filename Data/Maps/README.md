# Map data directory

このディレクトリはワールドマップ／グリッドの外部データ（マップ定義、ロケーション配置、スポーンポイント等）を格納します。

- 使用形式: TOML を想定（`Tomlyn` をプロジェクトに追加済み）。
- ファイル命名: `*.toml`（例: `example_map.toml`）
- 配置場所: `Data/Maps/`（ここに置くとアプリから読み込みやすくなります）

運用メモ:
- マップ読み込みロジックは `WorldGridService` に実装するか、別途 `MapLoader` サービスを追加してください。
- 開発時は `example_map.toml` を参考にして新しいマップを作成してください。
