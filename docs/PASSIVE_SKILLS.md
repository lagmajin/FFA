# Passive Skills by Job

This document lists the passive skills added to each job in the project.

## Basic Jobs

- Warrior
  - 被ダメージ-5%（常時）
  - 挑発成功率+5%

- Monk
  - クリティカル率+3%
  - 連撃時ダメージ+5%

- WhiteMage
  - 回復効果+10%
  - 状態異常耐性+5%

- BlackMage
  - 魔法攻撃力+8%
  - MP 回復速度+5%

- Ranger
  - 遠距離会心率+5%
  - 移動速度+5%

- Paladin
  - 被ダメージ-3%
  - 味方回復効果+5%

- DarkKnight
  - 与ダメージ+5%
  - HP 吸収効果+3%

- Bard
  - 味方の攻撃力+3%（範囲）
  - MP 回復効果+3%

- Thief
  - 回避率+5%
  - ドロップ率+3%

- Ninja
  - 初手回避率+5%
  - 手裏剣ダメージ+4%

## Advanced Jobs

- HolyKnight
  - 被ダメージ-8%
  - 周囲味方の防御+3%

- DeathKnight
  - 与ダメージ+7%
  - 復活時HP回復+10%

- ArchMage
  - 魔法威力+10%
  - 詠唱速度+5%

- BeastMaster
  - ペット攻撃力+8%
  - ペットHP+10%

- Duelist
  - 会心率+6%
  - 回避時反撃+3%

- Grandmaster
  - 全能力+5%
  - 全属性耐性+3%

***

These passive skills are descriptive. Integration into actual gameplay mechanics (applying bonuses to calculations) requires updating the relevant systems (damage calc, stat aggregation, combat resolution, etc.).
