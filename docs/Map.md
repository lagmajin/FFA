# ワールドマップシステム仕様

クラシックJRPG（ドラゴンクエスト・ファイナルファンタジー初期作品）スタイルの2Dタイルマップ移動システム。

---

## マップ構造

### サイズ

| 項目 | 値 |
|------|-----|
| ワールド全体 | 20 × 15 タイル |
| ビューポート | 15 × 11 タイル |
| プレイヤー位置 | ビューポート中央 固定 (HalfW=7, HalfH=5) |

### 座標系

- X軸: 西(0) → 東(19)
- Y軸: 北(0) → 南(14)
- ビューポートのワールド座標変換式:
  ```
  wx = PlayerX - 7 + sx
  wy = PlayerY - 5 + sy
  ```
  （sx=0〜14, sy=0〜10 がスクリーン座標）

## 移動システム

### 操作方法

| 操作 | 入力 |
|------|------|
| 上移動 | `↑` / `W` |
| 下移動 | `↓` / `S` |
| 左移動 | `←` / `A` |
| 右移動 | `→` / `D` |
| Dパッド | 画面右の ▲▼◀▶ ボタン |
| クリック移動 | ビューポート内タイルをクリック（移動可能タイルのみ）|

### 移動ルール

- 隣接タイルへ1歩ずつ移動（キーボード・Dパッド）
- クリックした座標に直接ジャンプ（Walkable=true のタイルのみ）
- 移動不可タイル (`mountain`, `peak`, `water`, `desert`, `swamp`) には入れない
- マップ外（X: 0〜19, Y: 0〜14 の範囲外）には移動不可

### キーボード入力の実装

JavaScript不要。Blazor の `tabindex="0"` + `@onkeydown` で実装。  
ページ読み込み後 `OnAfterRenderAsync` 内で `ElementReference.FocusAsync()` を呼び自動フォーカス。

## データ永続化

プレイヤーの現在座標は `User.MapX` / `User.MapY` に保存される。  
移動のたびに `UserService.UpdateUser(currentUser)` で LiteDB に書き込む。

| プロパティ | デフォルト値 | 説明 |
|-----------|------------|------|
| `User.MapX` | 10 | プレイヤーX座標 |
| `User.MapY` | 7 | プレイヤーY座標 |

## ビジュアル仕様

| 項目 | 仕様 |
|------|------|
