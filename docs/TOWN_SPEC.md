# 町ページ仕様書

## 概要
街のメイン画面。プレイヤーがいる街の情報表示と、街内外への移動を行う。

## 画面構成（2カラムレイアウト）

### 左側：メインコンテンツ

#### ヘッダー
- 街名
- 街の説明
- 天候・時間帯表示（☀️/🌅/🌙 + 時刻）
- ゲーム内日付

#### 街情報バー
- 街のタイプ（首都/一般街/田舎）
- 人口
- 繁栄度
- 座標（X, Y）
- 所属国
- 特産商店（有りの場合）

#### プレイヤーステータス
- ユーザー名
- レベル、ジョブ
- 持有货币（Gil、Premium）
- HPバー
- EXPバー
- 移動スタミナバー

#### クイックリンク
- クエスト（未完了数）
- メール（未読数）
- フレンド（好友数）
- ギルド（加入状況）
- ログインボーナス（受取状態）

#### 街の施設リスト
- 宿屋（HP全回復）
- 銀行（預金額表示）
- 各施設（アイコン + 名前 + 説明）

#### 周辺のフィールド（8方向）
- 北、北東、東、南東、南、南西、西、北西
- 各方向の地名（または「未探索」）
- クリックで 해당 フィールドへ移動

#### 他の街への移動
- 所属国の他の街へのリンクボタン

#### マップ移動モード（条件表示）
- 街のAvailableFieldsが未定義の場合に表示
- 4方向移動ボタン（⬆️北/⬇️南/➡️東/⬅️西）
- 現在地名称・座標表示
- 場所タイプ別のアクション：
  - 町 → 「町に入る」
  - フィールド/森 → 「フィールドで探索」
  - ダンジョン → 「ダンジョンに入る」
  - 川 → 「釣りをする」
  - 山 → 「採掘する」

### 右側：アクションボタン

#### 第1グループ（移動系）
```
AvailableFieldsあり → 「🌲 フィールド」ボタン
AvailableFieldsなし → 「🗺️ マップ移動」ボタン
```
- 宿屋
- 銀行
- 酒場

#### 第2グループ（商店）
- 武器屋
- 防具屋
- 装飾品屋
- 消耗品屋

#### 第3グループ（管理）
- 武器管理
- 防具管理
- 装飾品管理

#### 第4グループ（スキル）
- スキルツリー
- アビリティ

#### 第5グループ（导航）
- ダッシュボード
- マップ

## データソース
- `TownService.GetTownsByCountryId()` - 街データ取得
- `FieldService.GetAllFields()` - フィールド一覧
- `MapService` - マップ座標変換（オフセット+5）
- `StaminaService` - スタミナ情報
- `QuestService` - クエスト数
- `MailService` - 未読メール数
- `FriendService` - フレンド数
- `GuildService` - ギルド情報
- `DailyRewardService` - ログインボーナス状態
- `TimeWeatherService` - 天候・時間帯
- `UserService` - プレイヤー情報

## 座標系
- 街座標：-3 ～ 3（TOMLデータ）
- マップ座標：0 ～ 9（10x10グリッド）
- 変換：`mapX = townX + 5`, `mapY = townY + 5`
