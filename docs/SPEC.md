この仕様書は、FFAオンラインRPGゲームの全ページについての仕様を定義する。

## 個別ページ仕様

### 1. ホーム画面 (`/`)

**概要**
- ゲームへの入口ページ
- 未ログイン時：ゲーム紹介、ログイン、新規登録、テストプレイボタン
- ログイン時：ダッシュボードへリダイレクト

**表示要素**
- チャンピオン情報（Sky Arena勝者）
- 総登録者数
- ランキング登録者数
- 最高レベル

**ナビゲーション**
- ログイン → `/login`
- 新規登録 → `/register`
- テストプレイ → テストアカウントで自動ログイン後 `/status`

---

### 2. ステータス画面 (`/status`)

**概要**
- プレイヤーの詳細なステータス表示
- 能力値の割り振り

**表示要素**
```
- ユーザー名
- Karma値
- 持有ゴールド（Gil）
- プレミアム通貨
- 職業（Job）
- レベル
- 経験値 / 次レベルまで
- ステータス（STR, DEX, INT, VIT, AGI, LUK）
- 未振り分けポイント
- 装備武器（攻撃力）
- 装備防具（防御力）
- 装飾品1, 2
- HP / 最大HP
- マスターレベル
- 転生回数
```

**機能**
- ステータスポイント割り当て
- 装備詳細表示

---

### 3. ダッシュボード (`/dashboard`)

**概要**
- クイックアクション詰め合わせ
- 現在地の基本情報

**表示要素**
- ユーザー名、Karma、Gil、Job、レベル
- 現在時刻、天候
- クイックアクションボタン

**ナビゲーション**
- 街へ → `/town`
- フィールドへ → `/field`
- ステータスへ → `/status`

---

### 4. 街画面 (`/town`)

**概要**
- 街の主要施設への入口
- NPCとの会話（予定）

**表示要素**
- 街名、説明
- 街タイプ（通常港町など）
- 人口、繁栄度
- 所属国
- 施設リスト
- イベントリスト

**ナビゲーション**
- 武器屋 → `/weapon-shop`
- 防具屋 → `/armor-shop`
- 装飾品屋 → `/accessory-shop`
- 消耗品屋 → `/consumables-shop`
- 宿屋 → `/inn`
- 銀行 → `/bank`
- 装飾品管理 → `/accessory-management`
- スキルツリー → `/skill-trees`
- アビリティ → `/abilities`
- ダッシュボード → `/dashboard`

---

### 5. 武器管理 (`/weapon-management`)

**概要**
- 所有武器の一覧表示
- 装備、強化、修理、売却

**表示要素**
- 武器リスト（名前、タイプ、攻撃力、强化レベル、耐久度）
- 各武器アクションボタン

**機能**
- 装備 → 武器を装備槽にセット
- 強化 → `/weapon-enhance/{id}`へ遷移
- 修理 → `/weapon-repair/{id}`へ遷移
- 売却 → ゴールド获得、武器削除

---

### 6. 防具管理 (`/armor-management`)

**概要**
- 所有防具の一覧表示
- 装備、強化、修理、売却

**表示要素**
- 防具リスト（名前、タイプ、防御力、强化レベル、耐久度）
- 各防具アクションボタン

**機能**
- 装備 → 防具を装備槽にセット
- 強化 → `/armor-enhance/{id}`へ遷移
- 修理 → `/armor-repair/{id}`へ遷移
- 売却 → ゴールド获得、防具削除

---

### 7. 装飾品管理 (`/accessory-management`)

**概要**
- 所有装飾品の一覧表示
- 2スロット分の装備、強化、修理、売却

**表示要素**
- 装着中装飾品（スロット1、スロット2）
- 所有装飾品リスト
- 各装飾品アクションボタン

**機能**
- 装備 → 空いているスロットにセット
- 強化 → `/accessory-enhance/{id}`へ遷移
- 修理 → `/accessory-repair/{id}`へ遷移
- 売却 → ゴールド获得、装飾品削除

---

### 8. 武器強化 (`/weapon-enhance/{id}`)

**概要**
- 武器の強化実行

**表示要素**
- 武器名、タイプ、攻撃力
- 現在の强化レベル / 最大强化レベル
- 强化成功率
- 强化費用
- 玩家持有金

**機能**
- 強化ボタン → 成功率高さとコストに基づいて強化
- 成功：新攻撃力、新しい强化レベル表示
- 失敗：コストのみ消费

---

### 9. スキルツリー (`/skill-trees`)

**概要**
- ジョブ別スキルツリー表示
- スキル習得

**表示要素**
- 使用可能スキルポイント
- ジョブ別スキルリスト
- 各スキルの詳細（必要レベル、消費SP、効果）

**機能**
- スキル選択 → 詳細表示
- 習得ボタン → スキルポイント消费、スキル習得
- 前提スキルチェック
- プレイヤーレベルチェック

---

### 10. アビリティ (`/abilities`)

**概要**
- アビリティの使用と習得

**表示要素**
- 所有アビリティリスト
- アビリティ詳細（コスト、クールダウン）
- 習得可能アビリティリスト

**機能**
- 使う → アビリティ效果適用、クールダウン設定
- 習得 → アビリティ習得

---

## ページ連携フロー

```
ホーム（未ログイン）
  ↓
ログイン/新規登録
  ↓
ステータス ←→ ダッシュボード
  ↓
街
  ├→ 武器屋 → 武器管理 → 武器強化/修理
  ├→ 防具屋 → 防具管理 → 防具強化/修理
  ├→ 装飾品屋 → 装飾品管理 → 装飾品強化/修理
  ├→ 消耗品屋
  ├→ 宿屋（HP回復）
  ├→ 銀行
  ├→ スキルツリー
  ├→ アビリティ
  └→ ダッシュボード

フィールド
  ↓
ダンジョン

ダッシュボード → マップ → ランキング
                → クエスト
                → 天空闘技場
                → ギルド
                → 国
                → 毎日報酬
                → 交易所
```

## 技術仕様

- **フレームワーク**: Blazor Server (InteractiveServer)
- **UIライブラリ**: MudBlazor
- **認証**: ASP.NET Core Cookie Authentication
- **データベース**: LiteDB
- **リアルタイム**: SignalR（WorldHub）
- **ページ라우팅**: Razor Pages
