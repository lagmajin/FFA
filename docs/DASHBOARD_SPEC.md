# ダッシュボード仕様書

## 概要
プレイヤーのホーム画面。プレイヤーのステータスと現在位置を表示し、主要な場所への移動を行う。

## 画面構成

### ヘッダー
- プレイヤー名での挨拶
- 現在時刻・天気情報の表示

### 左側：プレイヤーカード
- アバターアイコン
- プレイヤー情報（ユーザー名、ジョブ、レベル、カルマ）
- 通貨（Gil、OldCoin）
- HPバー（現在HP/最大HP）
- EXPバー（現在EXP/必要EXP）
- ステータス（STR、DEX、INT、VIT）

### 位置情報カード
- 現在地のアイコンと名前
- 座標表示（X, Y）
- 最終ログインIP

### 右側：アクションボタン
- プレイヤーの現在位置に基づく動的表示

## アクションボタン仕様

### 位置ベースの表示
```
現在地が Town    → 「🏠 街へ」ボタン
現在地が Field   → 「🌲 フィールドへ」ボタン
現在地が 未定義  → 「🆘 街へ」ボタン（救済措置）
```

### 救済措置
- 位置情報が未定義の場合、所属国の街へランダムで移動
- 所属国がない場合は全街からランダム選択

### 固定ボタン
- 「📊 ステータス」ボタン（常に表示）

## データソース
- `WorldGridService.GetOrCreatePlayerPosition()` - プレイヤー位置取得
- `LocationType` enum (Town, Field, Forest, Mountain, Dungeon, Lake, Desert, Volcano, Snow, Sea)
- `UserService` - プレイヤー情報
- `TownService` - 街データ（救済措置用）
